# GUI Design Overview
The datapipe GUI uses one window with five tabs:  Input, Decrypt, Encrypt, Output, and Run.  
## Input tab
The Input tab has a dropdown selector to select the input to the datapipe.  There is only one input to the datapipe. Depending on the type of input selected, form fields are added or removed from the area below the dropdown selector so that all of the needed parameters for the selected input type can be provided.  The bottom right of the Input tab has a right-arrow button to go to the Decrypt tab.  See the mockup graphic in `design/GUI_concept-input_tab.webp`.
## Decrypt tab
The Decrypt tab has a "Decrypt?" label and a checkbox that indicates if a decryption stage should be run.  There is a "51-byte UTF-8 Decryption Key:" label and a text entry field for the 51-byte UTF-8 decryption key. If the checkbox is unchecked, the text entry field is disabled.  If the checkbox is checked, the text entry field is active and requires a 51-byte UTF-8 decryption key to be entered.  The bottom left of the Decrypt tab has a left-arrow button to go to the Input tab.  The bottom right of the Decrypt tab has a right-arrow button to go to the Encrypt tab.  See the mockup graphic in `design/GUI_concept-decrypt_tab.webp`.
## Encrypt tab
The Encrypt tab has a "Encrypt?" label and a checkbox that indicates if an encryption stage should be run.  There is a "51-byte UTF-8 Encryption Key:" label and a text entry field for the 51-byte UTF-8 encryption key.  There is also a "Generate Key" button that will generate a random encryption key and place it in the text entry field. If the checkbox is unchecked, the text entry field and "Generate Key" button are disabled.  If the checkbox is checked, the text entry field and "Generate Key" button are active and the text entry field requires a 51-byte UTF-8 decryption key to be entered.  The bottom left of the Encrypt tab has a left-arrow button to go to the Decrypt tab.  The bottom right of the Encrypt tab has a right-arrow button to go to the Output tab.  See the mockup graphic in `design/GUI_concept-encrypt_tab.webp`.
## Output tab
The Output tab has a dropdown selector to select an output for the datapipe.  There must be at least one output to the datapipe, but there may be up to 64 outputs to the datapipe.  Depending on the type of output selected, form fields are added or removed from the area below the dropdown selector so that all of the needed parameters for the selected output can be provided. The bottom left of the Output tab has a left-arrow button to go to the Encrypt tab.  The bottom right of the Output tab has a right-arrow button to go to the Run tab.  The bottom center of the Output tab has a "+" button that adds an additional output to the Output tab.  When the "+" button is clicked, a horizontal rule and additional output section are added below the bottom output form fields, but above the three bottom buttons of the Output tab.  Each output section after the first output has a dropdown selector to select the output type and space for the output's form fields to provide all of the needed parameters for the selected output type.  Directly to the right of the dropdown selector is a "-" button.  This "-" button is only found for outputs after the first output; the first output does not have a "-" button.  When the "-" button is clicked, it removes the corresponding output section, form fields, and horizontal rule, thereby removing the output.  The first output does not have a "-" button because there must be at least one output.  The right side of the Output tab has a scroll bar for scrolling through all of the outputs.  If the maximum number of outputs are added, the bottom center "+" button is disabled.  See the mockup graphic in `design/GUI_concept-output_tab.webp`.
## Run tab
The Run tab has a top left "Load config" button that opens a file selector dialog box to select a saved config file containing a datapipe configuration.  A loaded configuration file is read and validated to ensure all of the needed parameters are present.  At the top center there is a "Save config" button that opens a file save dialog box used to save the current datapipe configuration to a file.  The current configuration is validated to ensure it is correct before saving the configuration to a file.  At the top left there is a "Clear config" button that clears the datapipe configuration from all of the tabs.  In the center, there is a status area that shows metrics and animated diagrams to illustrate data transfer statistics, data transfer rates, elapsed time, current status, and any errors that occur.  At the bottom left there is a left-arrow button to go to the Output tab.  At the bottom center there is a "Stop Datapipe" button that is used to stop the currently running datapipe.  At the bottom left there is a "Start Datapipe" button used to start the datapipe using the current configuration found in the GUI tabs.  The "Stop Datapipe" button is disabled unless the datapipe is currently running.  The "Start Datapipe" button is disabled unless all of the required datapipe parameters are provided.  If any required datapipe parameters are not provided, the status area shows one or more messages that indicate which required parameters are missing or any errors that occurred when providing the required parameters.  See the mockup graphic in `design/GUI_concept-run_tab.webp`.
